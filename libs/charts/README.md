# @amangalvedhekar/charts

Shared chart primitives for BudgetBuddy applications. The initial API is a small,
intentional subset of `react-native-gifted-charts` so applications import chart
renderers through one package.

```tsx
import { LineChart, PieChart } from '@amangalvedhekar/charts';
```

Install one gradient peer for the target environment: `expo-linear-gradient` in
Expo applications or `react-native-linear-gradient` in React Native CLI apps.
